# AI Management Consultant

A multi-agent AI business consulting system built using the OpenAI Agents SDK.

## Features

- Business problem analysis
- Market research using web search
- Competitor benchmarking
- Financial analysis
- Percentage-change calculation
- ROI calculation
- Strategic recommendations
- Final consulting report generation
- Multi-agent handoffs

## Agents

1. Business Analyst
2. Market Research Agent
3. Benchmarking Agent
4. Financial Analysis Agent
5. Strategy Advisor
6. Report Writer
7. Consulting Manager

## Tools

- WebSearchTool
- Percentage Change Calculator
- ROI Calculator

## Technologies

- Python
- OpenAI Agents SDK
- OpenAI API
- Python-dotenv
